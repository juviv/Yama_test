# Yamaguchi

Основа для обычного лендинга: Vue, JavaScript, Vite и Tailwind CSS.
Без API, Pinia, роутера и тестовых библиотек.

## Запуск

Зависимости уже установлены. Из папки проекта запустите:

```powershell
npm run dev
```

Откройте http://127.0.0.1:5174 в браузере. Изменения файлов автоматически
отображаются на странице. Остановить сервер: Ctrl+C в терминале.
Команда `npm start` запускает тот же сервер.

При переносе проекта или после удаления node_modules сначала выполните `npm ci`.
Использован Node.js 24.11.1; версия записана в .nvmrc.

## Структура

- `src/App.vue` — основная страница.
- `src/components/` — компоненты и секции лендинга.
- `src/style.css` — подключение Tailwind и общие стили.
- `src/components/SlideWheel.vue` — колесо навигации; `currentSlide` принимает индекс 0, 1 или 2, событие `select` передаёт выбранный индекс.
- `src/assets/css/presentation.css` — адаптивная композиция слайдов и анимация колеса.
- `public/` — статичные файлы (изображения, шрифты, favicon).
- `vite.config.js` — настройки сборки и локального сервера.

Например, `public/images/photo.jpg` доступен в разметке как `/images/photo.jpg`.
Алиас `@` указывает на `src`.

Слайды переключаются циклически с анимацией: колёсиком мыши, свайпом,
кнопками колеса, стрелками клавиатуры, PageUp/PageDown или пробелом.
На мобильных длинный слайд сначала прокручивается до края, затем переключается.

## Сборка

```powershell
npm run build
npm run preview
```

Готовые файлы появляются в `dist/`. Предпросмотр сборки: http://127.0.0.1:4174.

## Окружение

Для Vue не требуется Python venv: зависимости изолированы в локальной папке
`node_modules`, команды используют локальный Vite. Точные версии зависимостей
сохранены в `package-lock.json`; `npm ci` восстанавливает их.
Глобально устанавливать Vue или Tailwind не нужно.

Tailwind подключён через официальный плагин `@tailwindcss/vite` и
`@import "tailwindcss"` в CSS. Классы можно сразу использовать в `.vue`-файлах.
